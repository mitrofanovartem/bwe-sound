# BWE Sound Frontend

Папка зарезервирована для клиентского приложения. Выбор фреймворка и структура остаются за frontend-разработчиком.

Пока backend предоставляет только технический endpoint:

- `GET http://localhost:8081/actuator/health`

Когда появится первый пользовательский API, его контракт будет храниться рядом с backend-сервисом в OpenAPI-формате.
